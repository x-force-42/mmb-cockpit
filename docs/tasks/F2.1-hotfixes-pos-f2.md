**1) Vitest excluir `.worktrees/**` do test discovery**

Atualmente o vitest roda testes na worktree de outras tasks
quando elas ficam montadas — duplicando 100% do suite e podendo
introduzir flakiness quando F3+ paralelizarem.

Em `vite.config.ts`, dentro de `test:`:

```ts
test: {
  globals: true,
  environment: "jsdom",
  setupFiles: "./src/setupTests.ts",
  css: false,
  exclude: [
    "**/node_modules/**",
    "**/.worktrees/**",
    "**/dist/**",
  ],
},
```

(O default do vitest inclui `node_modules` e `dist` — repetir
explicitamente é necessário ao sobrescrever `exclude`. Não esqueça
de incluí-los junto com `.worktrees/**`.)

**Validação**: deixe a worktree F2 montada e rode `npm run test:run`.
Deve listar 10 testes (não 20).

**3) `task-end.sh` suportar squash merges**

`scripts/task-end.sh` linha 36 usa
`git merge-base --is-ancestor "$BRANCH" master`. Esse check **falha
quando o PR foi mergeado via squash** — o commit da branch não é
ancestor literal do master mesmo tendo sido absorvido. Foi
exatamente o que aconteceu com F2 (worktree não foi limpa).

A regra de merge no projeto agora é **squash padrão** (vide
`PROTOCOLO.md` atualizado nesta task). Então o script precisa
detectar tanto FF-merge quanto squash.

Substitua a checagem por uma que cobre os dois casos:

```bash
# Confere mergeada (FF ou squash)
if git show-ref --verify --quiet "refs/heads/$BRANCH"; then
  # 1) Caso FF/merge regular: branch é ancestor de master
  if git merge-base --is-ancestor "$BRANCH" master; then
    :  # mergeada via FF/merge tradicional
  # 2) Caso squash: branch não tem commits que não estejam representados
  #    como patch em master. `git cherry` mostra "+" pra commits ausentes,
  #    "-" pra presentes equivalentes. Se nenhum "+" sobrou, foi squashada.
  elif [ -z "$(git cherry master "$BRANCH" | grep '^\+' || true)" ]; then
    :  # mergeada via squash
  else
    echo "ERRO: branch $BRANCH não está mergeada em master."
    echo "Mergeie o PR primeiro, ou destrutivo manualmente:"
    echo "  git worktree remove --force $WORKTREE_PATH"
    echo "  git branch -D $BRANCH"
    exit 1
  fi
fi
```

E também: na linha que apaga a branch (atualmente `git branch -d`),
trocar pra **`git branch -D`** quando foi squash, porque squash
não atualiza o reflog do branch e `-d` recusa apagar branch "não
mergeada" do ponto de vista do reflog.

Pra simplificar: usar `git branch -D` sempre — você já validou que
foi mergeada acima. Não é destrutivo nesse ponto.

**Validação**: rode `scripts/task-end.sh F2` na raiz. Deve limpar
sem erro a worktree `.worktrees/F2-ui-shell/` e a branch `task/F2-ui-shell`.
